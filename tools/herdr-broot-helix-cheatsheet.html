herdr / broot / helix

brootで選んだファイルを、右パネルのhelixで開く

Herdr上でbrootをファイルマネジャーとして使い、選択したファイルを右側に新しいパネルを開いてHelixで編集するための設定と、はまりやすい落とし穴(設定ファイルの場所)をまとめた自分用チートシート。

brootでファイルにカーソル → F2(または :er) → 右に新パネルでhelixが開く → :q で閉じる
前提: Herdr(タブ/ペイン管理)
broot(ファイルマネジャー)
Helix(hxコマンド)
jq(JSON解析)
① 設定ファイルの場所(落とし穴)/ ② スクリプト設定/ ③ 仕組みと注意点/ ④ パネル幅の調整

① まず設定ファイルの場所を確認する

brootは環境によって設定形式・分割の仕方が異なる。編集する前に必ず実際のパスを確認すること。

はまりポイント: ~/.config/broot/conf.toml が存在しない/効かない場合がある。
macOSでは conf.toml ではなく conf.hjson(HJSON形式)が使われ、さらにverbの定義は本体ではなく verbs.hjson という別ファイルに分離されていることがある。
  1. 1broot起動中に ? キーを押してヘルプ画面を開く → 実際に読み込んでいる設定ファイルの絶対パスが表示される(これが「正解」)
  2. 2典型例: ~/.config/broot/conf.hjson の imports: セクションで verbs.hjson を読み込む構成になっている
  3. 3verbの追記先は ~/.config/broot/verbs.hjson(conf.hjson本体ではない)

② 右パネルでhelixを開く

yaziの時と同じ発想。brootの「選択ファイルを引数に外部コマンドを実行するverb」機能と、Herdrのコア機能である pane split / pane run を組み合わせる。

~/.config/broot/open-right.sh
#!/usr/bin/env bash
set -euo pipefail
file="$1"

# 呼び出し元(=brootが動いているペイン)を右に分割
resp=$(herdr pane split --current --direction right --ratio 0.6 --focus)
pane_id=$(printf '%s' "$resp" | jq -r '.result.pane.pane_id')

[ -n "$pane_id" ] && [ "$pane_id" != "null" ] || exit 1

# 新ペインでhelixを起動し、終了したらペイン自体も閉じる
herdr pane run "$pane_id" "hx $(printf '%q' "$file"); herdr pane close $pane_id"
chmod +x ~/.config/broot/open-right.sh
~/.config/broot/verbs.hjson(既存の verbs: [ ... ] 配列に追記)
{
    invocation: "edit-right"
    key: "F2"
    shortcut: "er"
    apply_to: "file"
    execution: "/Users/YOUR_USER/.config/broot/open-right.sh {file}"
    leave_broot: false
}

使い方

  1. 1Herdrのペインで broot(br)を起動する
  2. 2開きたいファイルにカーソルを合わせ、F2(または :er と入力してEnter)
  3. 3右側に新パネルが開き、helixがそのファイルを編集する。broot自体は左に残る
  4. 4helix側で :q(または :wq / :q!)すると、右パネルごと自動的に消える

③ 仕組みと注意点

  • herdr pane split --current --direction right が、呼び出し元(brootのペイン)を右に分割し、新しいペインIDをJSONで返す。Herdr本体のコア機能で、外部プラグイン不要。
  • herdr pane run <pane_id> "<command>" が新ペインへコマンドを送信・実行する。
  • 送るコマンドを hx file; herdr pane close $pane_id と ; で連結しているのがポイント。終了方法(:q/:wq/:q!)に関わらずパネルが自動で消える。
  • leave_broot: false を忘れると、verb実行と同時にbroot自体が終了してしまう。
  • --current は呼び出し元プロセスが継承する HERDR_PANE_ID を見て動くため、このスクリプトはbrootが動いているペインの中から実行される必要がある(brootのverb実行はその子プロセスとして起動されるので条件を満たす)。
  • brootの設定ファイル(conf.hjson / verbs.hjson)はホットリロードされない。編集したら一度brootを完全に終了し、起動し直す。
  • jq が必要(JSONレスポンスから pane_id を取り出すため)。

④ パネルの幅を調整する

これはHerdr側の機能なので、yaziでもbrootでも共通。

A. スクリプトで固定比率を指定

--ratio は0〜1の小数で、新しくできるパネルが全体の何割を占めるかを指定する。

herdr pane split --current \
  --direction right \
  --ratio 0.6 \
  --focus

0.6 → helix側60% / broot側40%。0.5で均等分割(省略時のデフォルト)。

B. 開いた後にキーボードで調整

Herdrのリサイズモードで手動調整できる(設定不要・デフォルト動作)。

  1. 1prefix(既定 ctrl+b)→ r でリサイズモードへ
  2. 2矢印キー(←↓↑→)で境界を移動
  3. 3Esc でリサイズモードを抜ける

モードに入らず1キーで調整したい場合(任意)

[keys]
resize_pane_left = "ctrl+shift+alt+left"
resize_pane_down = "ctrl+shift+alt+down"
resize_pane_up = "ctrl+shift+alt+up"
resize_pane_right = "ctrl+shift+alt+right"
注意: ctrl+shift+alt+矢印 は環境によってOSやターミナル側のショートカットと衝突する可能性がある。設定前に自分の環境で空いているか確認する。
