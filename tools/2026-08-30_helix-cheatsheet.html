Helix公式チュートリアル(hx --tutor)の内容をもとにした早見表です。色は押している/入るモードを表します — NOR Normal / INS Insert / SEL Select / CMD Command / MAT Match / WIN Window。左のモード名クリックで絞り込み、検索欄でキーや説明文からも検索できます。

01

Getting Started

CMD
h j k lカーソルを 左/下/上/右 に移動
dカーソル位置の選択(文字)を削除
:コマンドモードに入る
:q / :quit終了(未保存の変更があると失敗する):q! / :quit! で変更を破棄して強制終了
:w / :write保存:wq / :write-quit で保存して終了
02

Insert Mode

INS
i選択の前からInsertモード
a選択の後からInsertモード(append)
I行頭(最初の非空白文字)からInsertモード
A行末からInsertモード
o下に新規行を開いてInsertモード
O上に新規行を開いてInsertモード
EscNormalモードに戻る
03

Motions & Selections

NOR
w次の単語の先頭まで選択
e単語の末尾まで選択
b単語の先頭まで後方選択
W E B同上、ただし空白区切りのWORD単位記号混じりの単語も1つとして扱う
c選択を変更(削除してInsertモードへ)
2w 3e …移動の前に数字を付けてn回繰り返す
vSelectモードに入る(移動が選択を拡張)v または Esc で抜ける
x現在行を選択、繰り返すと次の行も追加
X行を選択(次行へは拡張しない)
;選択を単一カーソルに折りたたむ
Alt-;選択のアンカーとカーソルを反転
04

Undo, Yank/Paste, Search

NOR
uアンドゥ
Uリドゥ
y選択をヤンク(コピー)
p / P選択の後/前に貼り付け削除・変更した内容も自動でヤンクされる。汚したくないときは Alt-d / Alt-c
Space y / Space pシステムクリップボードでヤンク/貼り付け
/ / ?前方/後方検索(正規表現対応)
n / N次/前の一致へ移動
05

Multiple Cursors & Select Command

NOR
C選択(カーソル)を次の行にコピーして追加
Alt-C選択(カーソル)を前の行にコピーして追加
,プライマリ選択だけを残す
s選択内で正規表現にマッチする箇所を選択検索置換をしたいときは % で全選択してから s
&選択を列として整列(align)
Alt-s選択を改行ごとに分割
06

Find & Replace Character, Repetition

NOR
f<ch>その文字を含めて選択(find)
t<ch>その文字の手前まで選択(till)
F / T同上、後方方向Vimと違い現在行に限定されない
r<ch>選択中の文字をchに置換
.直前の挿入操作を繰り返す
Alt-.直前の f / t 選択を繰り返す
07

Replace, Join, Indent, Increment

NOR
R選択をヤンク済みテキストで置換
J選択内の行を結合
> / <選択をインデント/アンインデント
Ctrl-a選択中の数値をインクリメント
Ctrl-x選択中の数値をデクリメント
08

Registers & Macros

NOR
"<ch>ヤンク/貼り付け先のレジスタを選択
Qマクロの記録を開始/停止(既定レジスタ @)
qマクロを再生
09

Search Selections, Jumplist, Labels

NOR
*選択を検索レジスタ(/)にコピー"/y のショートハンド
v + n/NSelectモード中は一致箇所を選択に追加していく
Ctrl-s現在位置をジャンプリストに保存
Ctrl-i / Ctrl-oジャンプリストを前方/後方へ移動
gw各単語に2文字ラベルを表示してジャンプ
10

Cycling Selections, Case, Split

NOR
) / (プライマリ選択を前方/後方へ循環
Alt-,プライマリ選択を除外
Alt-) / Alt-(選択の中身を前方/後方へ循環(位置ではなく内容が入れ替わる)
~選択の大文字/小文字を反転
` / Alt-`選択を小文字化/大文字化
S選択を正規表現で分割
11

Comments

NOR
Ctrl-c選択/カーソル行のコメントをトグル複数行選択・マルチカーソルにも対応
12

Match Mode

MAT
mMatch modeに入る
mm対応する括弧へジャンプ
mi( / mi{ / mi" …括弧・引用符の内側を選択(区切り文字は含まない)
ma( …括弧・引用符の外側を選択(区切り文字も含む)
ms( …現在の選択を指定の区切り文字で囲む(surround)
md( …周囲の区切り文字を削除
mr([周囲の区切り文字を別のものに置換(例: () → [])
13

Windows & Splits

WIN
Ctrl-wWindow modeに入る
Ctrl-w v / Ctrl-w s現在のバッファを垂直/水平に分割
Ctrl-w nv / Ctrl-w ns新規(空)バッファで垂直/水平分割
Ctrl-w h/j/k/l左/下/上/右の分割へ移動
Ctrl-w w次の分割へ移動
Ctrl-w q / Ctrl-w o現在の分割を閉じる / 他をすべて閉じる
Ctrl-w t隣接する分割の向きを入れ替え(transpose)
Ctrl-w H/J/K/L分割を左/下/上/右にスワップ
:vs [name] / :hs [name]垂直/水平分割で開く(ファイル名指定可)
Space fファイルピッカーを開く
Ctrl-v / Ctrl-sピッカーで選択したファイルを垂直/水平分割で開く
Helix公式チュートリアル(hx --tutor)より作成。バージョンにより挙動が異なる場合があります。
