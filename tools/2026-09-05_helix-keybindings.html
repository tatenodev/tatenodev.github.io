config.toml に追加する便利キーバインド

相対パスのコピーと同じ「コマンド展開（%{...}）＋:sh」の考え方で組める、他にも登録しておくと便利なキーバインドをまとめました。Helix 自体の標準機能ではなく、すべて自作の設定です。追加先は ~/.config/helix/config.toml。

01パスをまとめてコピーする一式

相対パス以外に、絶対パス・ファイル名のみ・ディレクトリのみ・「相対パス:行番号」も Spacel 配下にまとめておくと、用途に応じて使い分けられます。

config.toml 
[keys.normal.space.l]
r = ":sh printf '%s' '%{buffer_name}' | pbcopy"
a = ":sh printf '%s' '%{file_path_absolute}' | pbcopy"
n = ":sh printf '%s' \"$(basename '%{buffer_name}')\" | pbcopy"
d = ":sh printf '%s' \"$(dirname '%{buffer_name}')\" | pbcopy"
p = ":sh printf '%s:%s' '%{buffer_name}' '%{cursor_line}' | pbcopy"

各キーの内容

キーコピーされる内容出力例
r相対パスsrc/main.rs
a絶対パス/Users/you/project/src/main.rs
nファイル名のみmain.rs
dディレクトリパスsrc
p相対パス:行番号src/main.rs:42
補足：%{file_path_absolute} は比較的新しく追加された変数です（2025年11月マージ）。お使いの Helix が古い場合は、代わりに :sh printf '%s' "$(realpath '%{buffer_name}')" | pbcopy を使ってください（realpath は Windows 標準では使えません）。
補足：ここでも echo -n ではなく printf を使い、余計な改行が入らないようにしています。

OS別：パイプ先コマンド

macOSpbcopy
Linux（X11）xclip -selection clipboard
Linux（Wayland）wl-copy -n
Windowsclip

使い方：Space → l → r / a / n / d / p

02選択コードを位置情報つきでコピー

AI チャットやコードレビューのコメントにコードを貼るとき、「どのファイルの何行目か」を一緒に控えておけると話が早くなります。:pipe-to を使うと選択範囲を丸ごとコマンドの標準入力として渡せるので、コード自体をキーバインドの文字列に埋め込む必要がなく、引用符が崩れる心配もありません。

config.toml（01の設定に追記） 
[keys.normal.space.l]
s = ":pipe-to (echo '%{buffer_name}:%{selection_line_start}-%{selection_line_end}'; cat) | pbcopy"

仕組み

echo でパスと行範囲のヘッダー行を作り、続く cat が選択テキスト（標準入力）をそのまま流し込みます。両方の出力をまとめて pbcopy に渡すことで、ヘッダー付きのコードがクリップボードに入ります。

使い方

v などでコードを選択 → Space → l → s。クリップボードには次のような内容が入ります。

src/utils.rs:12-18 fn add(a: i32, b: i32) -> i32 { a + b }

pbcopy の部分は 01 の OS別表と同じように置き換えてください。

コマンド展開で使える変数の一覧は公式ドキュメントを参照：docs.helix-editor.com/command-line.html
